Why the Mac wins for local AI at this price

The number that matters for Ollama is how much memory a model needs to sit in — not raw clock speed:

  • 7–8B model (4-bit) ≈ 5 GB · 14B ≈ 9 GB · 32B ≈ 20 GB · 70B ≈ 40 GB
  • Apple Silicon shares one unified memory pool between CPU and GPU — so 48GB means a 70B model actually fits.
  • NVIDIA laptops split memory: a 16GB RTX 5080 can only hold ~14B comfortably; 32B+ spills to slow system RAM.

The one honest trade-off

On small models (7B–14B), a Windows RTX 5080/5090 generates tokens faster (higher memory bandwidth). But at $4,000 AUD, every RTX 5080 laptop is $4,500–5,900 — over budget — and none can run a 70B model at all. The Mac trades a little speed on small models for the ability to run much bigger models.
